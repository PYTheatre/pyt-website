## 5. Traps found today

- **Astro does not scope inside `:has()`.** `.x:has(:global(#id))` compiles
  to an invalid selector and the rule silently drops. Wrap the WHOLE
  selector: `:global(.x:has(#id))`. (ways-to-support.astro, `#dd-container`.)
- **The local `python3 -m http.server --directory dist` dies on every
  rebuild** (dist is deleted). Restart it after each build; `curl` first.
- **Colour transitions (0.18s) fool immediate screenshots** — a hover
  state read straight after adding a class shows the OLD colour. Wait
  ≥350ms or inject `*{transition:none!important}` for mockups.
- **GitHub "new file" links**: the filename box is pre-filled from
  `?filename=`; content pasted there too creates a file with the content
  as its name. Tell the PM: paste only into the editor.
- **Double the Donation's script can't load in the sandbox** — the widget
  can only be checked on the preview; styling goes through `#dd-container`
  (their documented route) or their portal's CSS Overrides field.
- CMS "Newsletter Signup Form" and "Contact Page" live under **About &
  Community**, not Site-wide (PM couldn't find them — say the group name).
